# Contributing to han-cli

Thanks for wanting to contribute to han-cli!

## Getting Started

1. Fork the repository.
2. Clone your fork.
3. Create a new branch.
4. Make your changes.
5. Run the tests.
6. Open a Pull Request.

## Running Tests

Run:

pytest

## Code Style

Keep the code simple, readable, and documented.

## Pull Requests

Please explain:

- What you changed
- Why you changed it
- How you tested it

Thank you for contributing!
